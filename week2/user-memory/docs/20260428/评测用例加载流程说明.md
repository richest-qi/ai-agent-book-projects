# User Memory 评测用例加载流程说明

本文档说明在 `week2/user-memory/main.py` 里选择 **Evaluation Mode** 后，`layer1/layer2/layer3` 这些 test cases 是如何被读取并加载进程序的。

## 1. 入口：在 `main.py` 进入评测模式

当你在交互菜单中选择 `1. Evaluation Mode` 时，会调用 `run_evaluation_mode(...)`。  
这个函数会先定位评测框架目录：

- 目标目录：`week2/user-memory-evaluation`
- 定位方式：`Path(__file__).parent.parent / "user-memory-evaluation"`

也就是说，`user-memory` 项目本身不会直接硬编码 60 条用例，而是借用旁边的 `user-memory-evaluation` 子项目来读用例。

## 2. 动态导入评测框架模块

`run_evaluation_mode(...)` 为了避免与当前项目同名模块冲突（如 `config`、`models`），做了以下动作：

1. 暂存并移除潜在冲突模块（`sys.modules`）
2. 将 `user-memory-evaluation` 临时插入 `sys.path` 首位
3. 动态导入：
   - `config`
   - `models`
   - `evaluator`
   - `framework`
4. 拿到 `framework.UserMemoryEvaluationFramework` 类
5. 恢复原始 `sys.path` 和模块状态

这一步的目的，是让评测模式使用评测框架自己的配置与数据模型，而不污染主程序运行环境。

## 3. 实例化框架时自动加载 test cases

`main.py` 中执行：

- `framework = framework_class()`

这里的 `framework_class` 实际上就是 `UserMemoryEvaluationFramework`。  
在 `week2/user-memory-evaluation/framework.py` 中，这个类的 `__init__` 会立即调用：

- `self._load_test_cases()`

因此，test cases 是在框架初始化时自动读入的。

## 4. `_load_test_cases()` 如何扫描文件

`_load_test_cases()` 的核心逻辑如下：

1. 固定遍历三个分类目录：
   - `layer1`
   - `layer2`
   - `layer3`
2. 每个分类目录下扫描 `*.yaml`
3. 对每个 YAML 调用 `_load_single_test_case(yaml_file)`
4. 解析成功且 `validate()` 通过的用例加入列表
5. 最终组装为 `TestSuite(name, version, test_cases=...)`
6. 输出加载数量（例如 `Loaded 60 test cases`）

所以你在控制台看到的 `Loaded 60 test cases`，就是所有 YAML 通过解析和校验后的总数。

## 5. YAML 文件的实际位置

默认路径来自 `week2/user-memory-evaluation/config.py` 中的 `TEST_CASES_DIR`：

- `week2/user-memory-evaluation/test_cases`

其目录结构为：

- `test_cases/layer1/*.yaml`
- `test_cases/layer2/*.yaml`
- `test_cases/layer3/*.yaml`

这些文件中定义了：

- `test_id`
- `category`
- `title`
- `description`
- `conversation_histories`
- `user_question`
- `evaluation_criteria`
- `expected_behavior`（可选）

## 6. 为什么菜单能按 LAYER1/LAYER2/LAYER3 展示

加载完成后，`main.py` 在“Run a test case”分支里调用：

- `framework.display_test_case_summary(show_full_titles=True, by_category=True)`

因此会按 category（`layer1/2/3`）聚合显示，并列出每个 `test_id` 和标题，这就是你看到的分层清单。

## 7. 一句话总结

Evaluation Mode 的 test cases 来自 `user-memory-evaluation/test_cases` 下的 YAML 文件；  
`main.py` 只是动态导入评测框架，真正的读取动作发生在 `UserMemoryEvaluationFramework.__init__ -> _load_test_cases()`。
