关于Embeddnig、Dense、向量检索、Top-K
- Embedding：把文本转换为向量
- Dense：向量大部分维度是非零值（不是稀疏的）
- 向量检索：拿你的向量去找最近的向量
- Top-K：返回最近的K个文档

文本进来→变成向量→放进索引→查询也变向量→找最近文档

dense-embedding实际干了这几件事：
1. 先把每篇文本变成向量
2. 把你的问题变成向量
3. 在所有向量中找到"离你问题最近"的几篇文本返回   

再用一个生活类比：  
1. 每篇文章都变成地图上的一个点 
2. 你的问题也变成地图上的一个点
3. 找到离你问题的最近的几个点   

ANNOY/HNSW就是两种"找到最近点"的加速方法：   
- HNSW：
    - 更准一些，改数据更方便
    - 更适合动态库，增删改更友好
- ANNOY：
    - 更省内存，查得也快，但更新删除没那么方便
    - 构建/内存特性不同，偏静态场景

项目中提供了4个接口：  
- `POST /index`：放入一篇文档
- `POST /search`：查相似文档
- `DELETE /index`：删一篇文档
- `GET /stats`：看当前状态           


小结：
- Sparse（DM25）：看"词有没有对上、对上多少"
- Dense：看"语义是否接近"（哪怕字面不完全一样）    
 

### 场景
- D1：如何修改收货地址
- D2：订单发货后可以拦截吗
- D3：退款多久能到账
- D4：发票怎么开   

用户来问一句：  
Q："东西已经寄出了，还能改地址吗？"   

### Sparse（BM25）可能怎么想
它会更依赖"词面是否重合"：  
- Q里有"寄出、改、地址"  
- D1里有"修改、收货地址"（有点像）
- D2里有"发货后、拦截"（意思也很像）  

如果词没完全对上（"寄出"vs"发货"，"改地址"vs"拦截"），有时排名就不稳定。  

#### 怎么理解BM25中的排名不稳定？
设文档：
- D1：发货后可以修改收货地址
- D2：订单发货后可以拦截  

设两个同义查询：  
- Q1：寄出后怎么改地址
- Q2：发货后怎么拦截  


| 查询\文档 | D1（修改地址） | D2（发货拦截） |
|---|---|---|
| Q1（寄出 改 地址） | `改/地址`命中较多 ✅✅ | `发货/拦截`命中少 ⚠️ |
| Q2（发货 拦截） | `发货`命中一点 ✅ | `发货/拦截`命中很多 ✅✅✅ |

所以很可能出现：

- Q1 -> **D1 第一**
- Q2 -> **D2 第一**   

这就是前面说的"排名不稳定"：  
**用户意图差不多，但换词后Top1变了**。


### Desne怎么做  
它不主要看字面词，而是看**语义距离**:   
1. 把D1-D4都编码成向量
2. 把Q也编码成向量
3. 看Q离谁最近  

结果常见会是：  
- Top1：D2（发货后是否还能改动，语义最接近）
- Top2：D1（改地址相关，也接近）  
- D3/D4很远   

重点：即使Q没出现"拦截"这个词，dense也可能把D2找出来，因为"寄出了还能改地址吗"和"发货后可否拦截"语义接近。     

**Dense检索擅长"同义改写、口语表达、词不完全一致"这种情况**。用户不一定用你文档里的原词，但系统能让找到对的内容。  
 
#### 举个例子
先固定 3 条文档 + 1 条查询：

- D1：发货后可以修改地址
- D2：退款多久到账
- D3：如何开具发票
- Q：东西寄出了还能改地址吗  

为了演示，先用2维向量（真实模型是1024维，这里是简化）。   

假设模型编码后得到：  
- D1 -> [0.90, 0.10]
- D2 -> [0.10, 0.95]
- D3 -> [-0.60, 0.20]
- Q -> [0.85, 0.20]  

##### 1）相似度怎么算
常用是余弦相似度： 
$$
\cos(a,b)=\frac{a\cdot b}{|a||b|}
$$

###### Q 和 D1
- 点积：`0.85*0.90 + 0.20*0.10 = 0.785`
- 模长：`|Q|=sqrt(0.85^2+0.20^2)=0.873`
- 模长：`|D1|=sqrt(0.90^2+0.10^2)=0.906`
- 余弦：`0.785 / (0.873*0.906) = 0.992`（非常高）
###### Q 和 D2
- 点积：`0.85*0.10 + 0.20*0.95 = 0.275`
- 模长：`|D2|=sqrt(0.10^2+0.95^2)=0.955`
- 余弦：`0.275 / (0.873*0.955) = 0.330`（低很多）
###### Q 和 D3
- 点积：`0.85*(-0.60) + 0.20*0.20 = -0.47`
- 模长：`|D3|=sqrt((-0.60)^2+0.20^2)=0.632`
- 余弦：`-0.47 / (0.873*0.632) = -0.852`（方向基本相反）
##### 2）检索结果 
所以 `top_k=3` 时，大致就是：
- D1: `0.992`
- D2: `0.330`
- D3: `-0.852`
