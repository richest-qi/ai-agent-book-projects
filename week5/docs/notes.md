## Coding Agent
Coding Agent的整体流程  
- 项目文档化
- 任务理解与需求澄清
- 编写设计文档
- 代码实现与测试
- 文档同步与交付   

Coding Agent的实现技巧  
- 并行工具调用与流式执行
- 上下文的精细化管理   
- 环境信息的动态注入
- 命令执行环境的状态持久化
- 即时的语法反馈   

Coding Agent中的搜索工具   
- 正则表达式内容匹配
- 文件名模式匹配
- 语义代码搜索
- 符号级定义与引用查找
- 搜索策略的组合使用   

Coding Agent中的文件编辑工具  
- 差异字符串与差异应用模型   
    Cursor早期：Diff String + Apply Diff Model ，效率低   
- 旧字符串到新字符串        
    Cursor现在、Claude Code：old string → new string   
- 行号定位机制   
- 类Vim编辑命令  
    选中→复制/删除→粘贴
- 字符串首尾匹配  
    找头、找尾，替换中间
