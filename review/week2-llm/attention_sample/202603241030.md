先用一句人话：

> 模型在理解一句话时，**一个词单看往往不够**，它要结合前后词来确定自己“到底是什么意思”。

---

## 为什么一个 token 要看别的 token？

因为语言有大量“必须看上下文”的情况。

### 例子 1：同一个词，不同上下文意思不同
- `bank`  
  - `river bank`（河岸）  
  - `bank account`（银行）  
如果只看 `bank` 这一个 token，你根本不知道它是哪种意思。

### 例子 2：代词指代
- `小明告诉小红，他明天请假。`  
“他”指谁？要看前面的名字和语法关系。

### 例子 3：翻译/时态/否定
- `I do like it` vs `I don't like it`  
`like` 这个词的语义受 `do / don't` 强烈影响。

---

## 所以 Transformer 在做什么？

它对每个 token 都会问一件事：

> “为了理解我自己，我应该参考句子里的哪些 token？参考多少？”

这就是“注意力”的本质。

- 看得多 → 权重大  
- 看得少 → 权重小

---

## “矩阵”只是把这个过程记成表格

你可以把它当成一个 Excel 表：

- 行：当前在理解哪个 token  
- 列：它参考了哪些 token  
- 表里的数：参考强度（权重）

所以“Attention 矩阵”不是新概念堆砌，本质就是：
**每个 token 对其他 token 的参考分配表**。

---

## 为什么还有“多头”？

单一“参考方式”不够。

可以把“多头”想成同一句话上有多个观察员：

- 有的头擅长看语法关系（主谓一致）
- 有的头看实体对齐（人名、地点）
- 有的头看长距离依赖（前后句关联）

多个头并行看，再合起来，理解会更稳。
