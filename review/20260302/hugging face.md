## Hugging Face 是什么网站？

**Hugging Face** 是一家做人工智能开源生态的平台公司，同时也是一个非常核心的 AI 模型社区网站。

它主要做三件事：

### 1️⃣ 模型托管平台（最核心）

类似“AI 模型界的 GitHub”。

- 你可以在上面找到：
  - 各种大模型（LLM）
  - 图像生成模型
  - 语音模型
  - embedding 模型
- 比如：
  - Llama 系列
  - Mistral
  - 各种中文模型

地址：
[https://huggingface.co](https://huggingface.co)

---

### 2️⃣ 开源库提供者

他们开发了非常流行的 AI 工具库：

- **Transformers**（最著名）
- Diffusers
- Datasets
- Accelerate

很多人用 Python：

```python
from transformers import AutoModel
```

背后就是 Hugging Face。

---

### 3️⃣ 在线推理平台

你可以：

- 在线测试模型
- 用 API 直接调用模型
- 甚至部署自己的模型
