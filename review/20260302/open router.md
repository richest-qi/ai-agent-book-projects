## OpenRouter 是什么网站？

**OpenRouter** 是一个“多模型 API 聚合平台”。

它不是模型研发公司。

它的核心功能是：

> 🔌 把多个大模型厂商的 API 聚合到一个统一接口。

比如：

你原本要分别接：

* OpenAI
* Anthropic
* Mistral
* Meta Llama
* Google Gemini

而 OpenRouter 做的事情是：

> 你只接入 OpenRouter，一个 API Key，就能调用上面所有模型。

它更像：

> AI 模型的“API 代理层 / 统一网关”

官网：
[https://openrouter.ai](https://openrouter.ai)
